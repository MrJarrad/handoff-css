# bindings-brief-images

`design-handoff-mediarow.json.gz` is the layer export from `jhd-v18-placed-2026-11-08` (screenshot `MediaRow`, node 5527:5397).
`design-handoff-mediarow.md` is a hand-made small brief beside it, the way the plugin and a link run write one: each screenshot is
`![name](data:image/png;base64,...)`. It holds the `MediaRow` image (a 1x1 PNG) and one image no frame names. Real briefs are not
checked in with their image bytes (the 29 Oct fixtures carry the placeholder `STRIPPED`), so this one is built by hand.
